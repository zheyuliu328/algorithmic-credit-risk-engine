# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities to zheyuliu328@gmail.com.

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Security Measures

- Gitleaks pre-commit hooks for secret detection
- Bandit static analysis for Python security issues
- Input validation on all data paths
- Audit logging for dangerous operations
