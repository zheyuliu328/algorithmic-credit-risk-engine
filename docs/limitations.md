# 项目限制与边界

## 明确不做什么

### 1. 不做合规声明
- 非 Basel III/IFRS 9/SR 11-7 合规系统
- 模型治理框架为概念文档
- 未获得任何监管认证

### 2. 不做真实征信
- 使用合成数据训练
- 百行/央行征信连接为架构设计
- 未接入真实征信数据源

### 3. 不做生产部署
- 未经过独立模型验证
- 未通过监管审计
- 演示级实现

### 4. 不做信贷决策
- 演示工具，不构成任何信贷建议
- 实际决策需人工审核
- 无法律责任承担能力

## 参考框架说明

| 框架 | 关系 | 说明 |
|:-----|:-----|:-----|
| Basel III | 对齐思路 | 设计参考 PD 估计方法，非合规认证 |
| IFRS 9 | 支持逻辑 | 演示 ECL 计算流程，非合规工具 |
| SR 11-7 | 参考框架 | 体现 MRM 思维，非合规声明 |

**重要**: 以上仅为设计参考，不构成任何合规声明。

## 使用边界

| 场景 | 是否适用 | 说明 |
|:-----|:---------|:-----|
| 面试演示 | ✅ | 展示风控建模能力 |
| 方法论学习 | ✅ | 理解评分卡与验证流程 |
| 银行风控系统 | ❌ | 需合规认证与审计 |
| 信贷审批 | ❌ | 需真实数据与监管批准 |
| 监管报送 | ❌ | 非合规系统 |

## 数据限制

| 限制 | 说明 |
|:-----|:-----|
| 合成数据 | 使用合成数据训练，未在真实数据上验证 |
| 特征数量 | 演示用简化特征集 |
| 样本规模 | 演示级样本量 |
| 时间跨度 | 未覆盖完整经济周期 |

## 模型限制

| 限制 | 说明 |
|:-----|:-----|
| 验证范围 | 基础验证指标，未覆盖全部监管要求 |
| 监控体系 | 概念设计，未实际部署 |
| 治理流程 | 文档框架，未经过实际审计 |
| 可解释性 | SHAP 演示，需业务规则补充 |

## 面试叙事建议

**可以说的**:
- "项目设计对齐 Basel III 框架思路"
- "参考 SR 11-7 的模型风险管理思维"
- "面向合规要求设计，便于后续审计"
- "这是一个演示模型验证方法论的工具"

**不能说的**:
- "这是一个 Basel III 合规的信用风险系统"
- "已通过 SR 11-7 合规认证"
- "可直接用于银行生产环境"
- "模型经过监管批准"

**转换示例**:
| 错误 | 正确 |
|:-----|:-----|
| "这是一个 Basel III 合规系统" | "这是一个面向 Basel III 框架设计的演示工具" |
| "符合 IFRS 9 要求" | "支持 IFRS 9 ECL 计算逻辑演示" |
| "生产就绪的模型" | "演示级的模型验证框架" |
